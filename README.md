# DataEngineer_Project1

🚀 Sales Data Engineering Project

📌 Project Overview

This project demonstrates an end-to-end Data Engineering pipeline using Python, SQL Server, PySpark, ETL, ELT, Data Warehousing, and Power BI. The objective is to ingest, transform, store, and visualize sales data to generate meaningful business insights.

🛠️ Technologies Used

- Python
- SQL Server
- PySpark
- ETL
- ELT
- Data Warehousing
- Power BI
- Git & GitHub

📂 Project Workflow

1. Import the sales dataset (CSV).
2. Validate and clean the data using Python.
3. Load the data into SQL Server.
4. Perform ETL and ELT processes.
5. Apply data transformations using PySpark.
6. Design Data Warehouse tables (Fact & Dimension).
7. Build interactive dashboards in Power BI.
8. Manage the complete project using GitHub.
